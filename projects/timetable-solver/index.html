Timetable solver using SAT

Choosing a university class is really a constraint problem. For every class, you can only attend one timeslot, and no other classes can overlap, where the fewer days you spend on campus the better. This tool turns those rules into boolean logic, then hands them to a SAT solver I built. It all runs in your browser.

Source code How it works

    How it works

    1. Converting the problem into boolean algebra

    Every class time is assigned one boolean variable: x = true means “I’m choosing this option”. Each rule then becomes a set of clauses. A clause is an OR of variables or their negations, and every clause must be true. This is conjunctive normal form (CNF), the standard input format for SAT solvers.

    • Exactly one option per class: One clause x₁ ∨ x₂ ∨ … ∨ xₙ (at least one), plus ¬xᵢ ∨ ¬xⱼ for every pair (at most one).
    • No clashes: If two options from different classes overlap: ¬a ∨ ¬b.
    • Blocked times and hours: An option during work or outside your hours becomes a single-literal clause ¬x.

    2. Counting days on campus using a sequential counter

    “At most k days on campus” is a counting constraint, and CNF can’t count directly. I added variables dMon, dTue, dWed, … for each day with the implication x → dday(x), then encoded “at most k of the d’s are true” using Sinz’s sequential counter. The counter adds O(n·k) auxiliary variables that track a running total, instead of the exponential number of clauses a naive encoding requires.

    3. How the solver works

    The solver in solver.js uses DPLL, a search that sets variables to true or false one at a time and backtracks when it reaches a contradiction. Whenever a clause has only one way left to be satisfied, the solver fills in that value straight away. This step is called unit propagation. To make it fast, each clause keeps watch on just two of its variables and is only rechecked when one of those two is ruled out, so the solver does not have to reread every clause after each step. When the solver has to make a guess, it favours variables that keep showing up in contradictions.

    4. Finding the best timetable

    A SAT solver can only answer yes or no: either a valid timetable exists or it does not. The “Minimise days” feature turns this into a search for the best answer. It solves once, counts how many days the timetable uses, and then asks whether a valid timetable exists with one fewer day. It repeats this until the answer is no (UNSAT). That final no proves that no timetable can use fewer days. The “Show another” feature adds a clause that rules out the current timetable, so the solver has to find a different one.
