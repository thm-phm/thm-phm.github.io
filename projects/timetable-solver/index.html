Timetable solver using SAT

Choosing uni classes is a constraint problem: one option per class, no clashes, nothing during work, and ideally as few days on campus as possible. This tool translates those rules into boolean logic and solves them with a SAT solver I wrote from scratch. Everything runs in your browser.

Source code How it works

    How it works

    1. The problem as boolean variables

    Every class option gets one boolean variable: x = true means "I'm taking this option". Each rule then becomes a set of clauses: ORs of variables or their negations, which must all be true. This is conjunctive normal form (CNF), the input format for every SAT solver.

    • Exactly one option per class. One clause x₁ ∨ x₂ ∨ … ∨ xₙ (at least one), plus ¬xᵢ ∨ ¬xⱼ for every pair (at most one).
    • No clashes. If two options from different classes overlap: ¬a ∨ ¬b.
    • Blocked times and hours. An option during work or outside your hours becomes a single-literal clause ¬x.

    2. Counting days with a sequential counter

    "At most k days on campus" is a counting constraint, and CNF can't count directly. I add a variable dMon, dTue, … for each day with the implication x → dday(x), then encode "at most k of the d's are true" using Sinz's sequential counter. The counter adds O(n·k) auxiliary variables that track a running total, instead of the exponential number of clauses a naive encoding needs.

    3. The solver

    The solver in solver.js is a DPLL search with two watched literals for unit propagation. Each clause only wakes up when one of its two watched literals becomes false, so propagation doesn't rescan every clause. Branching favours variables that keep showing up in conflicts. It's tested against brute force on 2,000 random formulas and on the pigeonhole principle, a classic unsatisfiable formula.

    4. From "is there a timetable?" to "what's the best timetable?"

    SAT only answers yes or no, so Minimise days turns it into optimisation. It solves once, counts the days used, then asks "is there a solution with one fewer day?" and repeats until the answer is UNSAT. That final UNSAT is a proof that no better timetable exists, not a guess. Show another adds a blocking clause that rules out the current timetable, so the solver has to find a different one.
